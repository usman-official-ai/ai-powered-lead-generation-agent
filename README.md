# AI-Powered Lead Generation & Lead Scoring Agent

## Project Overview
This project builds an intelligent system that discovers business leads from public sources, collects company information, analyzes websites, and prepares data for ML-based lead scoring.

## Business Problem
Sales teams spend hours manually finding and qualifying leads. This project automates lead research and prepares structured data for machine learning.

## Project Objective
- Collect 50 business leads
- Analyze company websites for services and contact info
- Create a structured dataset with lead quality scoring
- Set up GitHub repository for future ML training

## Dataset Structure
| Column | Description |
|--------|-------------|
| Company Name | Name of the business |
| Website | Company URL |
| Country | USA |
| Industry | AI/SaaS/Web/Mobile App Development |
| Contact Page | Yes/No |
| Company Services | Services offered by the company |
| Contact Form | Yes/No |
| Lead Quality | High/Medium/Low |

## Data Sources
